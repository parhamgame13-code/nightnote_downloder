# 🤖 ربات دانلودر گروپی

ربات تلگرامی پیشرفته برای دانلود محتوا از یوتیوب، اسپاتیفای، اینستاگرام، تیک‌تاک و بیش از 1800+ سایت دیگر!

## ✨ ویژگی‌ها

✅ **دریافت لینک در گروپ یا خصوصی** - لینک رو بفرستید تا خودکار دانلود شود
✅ **اطلاعات کامل موسیقی** - هنرمند، آلبوم، مدت زمان، پوستر
✅ **انتخاب کیفیت** - انتخاب بین کیفیت‌های مختلف ویدیو
✅ **پشتیبانی پلی‌لیست** - دانلود چندین ویدیو (از طریق yt-dlp)
✅ **کش هوشمند** - عدم دانلود تکراری، ارسال فوری از کش
✅ **آمار روزانه** - تعداد دانلود، حجم، سایت محبوب
✅ **پاک‌سازی خودکار چت** - پیام «در حال دانلود» بعد از اتمام کار پاک می‌شه
✅ **ریپلای + ری‌اکشن** - فایل به پیام اصلی کاربر ریپلای می‌شه، موفقیت 👍 و شکست 👎
✅ **دکمه‌ی تلاش دوباره** - رو خطاها یه دکمه‌ی retry هست
✅ **معرفی خودکار در گروه** - وقتی بات به گروه اضافه می‌شه خودش رو معرفی می‌کنه
✅ **استخراج لینک از متن آزاد** - اگه کاربر قبل/بعد لینک یه توضیح هم بنویسه، مشکلی نیست
✅ **پشتیبانی 1800+ سایت** - با yt-dlp، به‌علاوه‌ی یه اسکرپر جدا برای APKPure
✅ **تنظیمات شخصی هر کاربر** - `/settings`: thumbnail دلخواه، افکت اسپویلر، ارسال به‌صورت فایل/سند، تغییر نام فایل (برای لینک‌های مستقیم/فایل‌های غیرپلتفرمی)، اسکرین‌شات پیش‌نمایش، timezone
✅ **پلی‌لیست ساندکلاود** - لینک یه ست (`soundcloud.com/.../sets/...`) رو بفرست، تک‌تک آهنگ‌هاش جدا دانلود و فرستاده می‌شن (دقیقاً مثل پلی‌لیست/آلبوم اسپاتیفای)
✅ **هشدار حجم قبل از دانلود** - برای لینک‌های فایل مستقیم (گوفایل/دراپ‌باکس/...)، اگه حجم بالای سقف تنظیم‌شده بود، قبل از دانلود تاییدیه می‌گیره
✅ **نمایش جایگاه صف** - وقتی چند دانلود هم‌زمان در جریانه، به کاربر نشون داده می‌شه
✅ **پاک‌سازی خودکار جاب‌های زامبی** - دانلودهایی که به‌خاطر کرش worker گیر کردن، خودکار بعد از مدتی FAILED می‌شن

### 👑 پنل ادمین
- `/stats` - آمار امروز
- `/topsites` - پرکاربردترین سایت‌ها (کل تاریخچه) + دامنه‌هایی که «unknown» تشخیص داده شدن
- `/userinfo <telegram_id>` (یا ریپلای رو پیام فوروارد شده‌ی کاربر) - breakdown سایت‌های یه کاربر خاص
- `/broadcast` - پیام همگانی به همه‌ی کاربرها یا فقط فعال‌های ۷ روز اخیر
- `/toggle` - روشن/خاموش کردن کلی بات

### 🔐 امنیت
- چک مالکیت رو دکمه‌های حساس (لغو/تلاش‌دوباره/تغییر کیفیت/تغییر نام) - جلوگیری از دستکاری دانلود کاربر دیگه با حدس زدن job_id
- فیلتر SSRF - رد کردن لینک‌هایی که به IP داخلی/لوکال سرور اشاره می‌کنن

### 🌐 سایت‌های تست‌شده و پشتیبانی‌شده

| سایت | نوع محتوا |
|------|-----------|
| یوتیوب (ویدیو/شورتز/موزیک) | ویدیو + کیفیت‌های مختلف، صوت |
| اینستاگرام (پست/ریلز) | ویدیو (نیاز به کوکی لاگین‌شده) |
| تیک‌تاک | ویدیو |
| اسپاتیفای، ساندکلاود، اپل‌میوزیک | صوت (اسپاتیفای و ساندکلاود: پلی‌لیست/آلبوم هم پشتیبانی می‌شه - هر ترک جدا فرستاده می‌شه؛ اسپاتیفای: زنجیره‌ی منبع یوتیوب → ساندکلاود → پیش‌نمایش رسمی ۳۰ ثانیه‌ای) |
| آپارات | ویدیو + پلی‌لیست |
| Pinterest (و `pin.it`) | عکس یا ویدیو - خودکار تشخیص داده می‌شه |
| APKPure | فایل APK (اسکرپینگ صفحه، نه yt-dlp) |
| گیت‌هاب / لینک مستقیم فایل | دانلود مستقیم (apk/exe/zip/mp3/mp4/...) |
| توییتر/X | اسکرپر اختصاصی (`utils/twitter_downloader.py`, GraphQL داخلی X)، نه yt-dlp |
| فیسبوک، ویمیو | از طریق yt-dlp (تست کامل نشده) |

⚠️ **APKMirror فعلاً پشتیبانی نمی‌شه** - سایتش لایه‌ی ضد-بات و توکن پویا داره که نیاز به کار بیشتری داره.

| سرور | Python 3.11+

## 📦 نصب

### 1. Clone کردن پروژه
```bash
git clone <repo>
cd downloader_bot
```

### 2. محیط مجازی
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# یا
venv\Scripts\activate  # Windows
```

### 3. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### 4. تنظیمات
```bash
cp .env.example .env
# .env را ویرایش کنید و BOT_TOKEN خود را وارد کنید
nano .env
```

### 5. دیتابیس
```bash
# SQLite خودکار ایجاد می‌شود
alembic upgrade head
```


### 6. Redis (اختیاری برای Celery)
```bash
# Redis را نصب و اجرا کنید
# Ubuntu/Debian:
sudo apt-get install redis-server
sudo systemctl start redis-server

# macOS:
brew install redis
brew services start redis

# یا Docker:
docker run -d -p 6379:6379 redis:latest
```

## 🎯 نحوه کار

### گروپ
1. **لینک فرستادن** - در گروپ یا چت خصوصی لینک ارسال کنید
2. **شناسایی** - بات نوع محتوا را تشخیص می‌دهد
3. **استخراج اطلاعات** - متادیتا (عنوان، هنرمند، آلبوم) استخراج می‌شود
4. **دانلود** - فایل به صورت موازی دانلود می‌شود
5. **ارسال** - فایل به گروپ یا چت شما ارسال می‌شود

### موسیقی
```
📌 عنوان: کوچه باغ
👤 هنرمند: بابک جهانبخش
💿 آلبوم: شاهراه
⏱ مدت: 04:32
```

## 🚀 استقرار

### systemd (Linux)

1. فایل service ایجاد کنید:
```bash
sudo nano /etc/systemd/system/downloader-bot.service
```

2. محتوا:
```ini
[Unit]
Description=Downloader Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/downloader_bot
ExecStart=/path/to/venv/bin/python -m bot.main
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

3. اجرا:
```bash
sudo systemctl enable downloader-bot
sudo systemctl start downloader-bot
sudo systemctl status downloader-bot
```

### Docker

یه `docker-compose.yml` کامل تو ریشه‌ی پروژه هست (redis + postgres + bot + worker + beat، به‌علاوه‌ی سرویس **telegram-bot-api** که پیش‌فرض فعاله - سرور محلی Bot API برای فایل‌های تا ۲ گیگ؛ کلیدهای api_id/hash پیش‌فرضِ عمومی دارن و از `.env` قابل بازنویسی‌ان):
```bash
docker compose up -d --build
```

یا دستی:
```dockerfile
FROM python:3.11-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
CMD ["python", "-m", "bot.main"]
```

## ❓ سوالات متداول

### بات در گروپ کار نمی‌کند
✅ مطمئن شوید بات **Admin** در گروپ است و دسترسی «حذف پیام‌ها» رو داره (وگرنه پیام‌های وضعیت پاک نمی‌شن)

### فایل خیلی بزرگ است
✅ حداکثر ۲۰۰۰ مگابایت تنظیم شده (با Local Bot API Server)

### موسیقی بدون "Unknown Artist" چطور؟
✅ yt-dlp متادیتا را بطور خودکار استخراج می‌کند

### اینستاگرام «empty media response» یا 404 می‌ده
⚠️ معمولاً یعنی کوکی `cookies/instagram.txt` منقضی شده. باید از یه مرورگر لاگین‌شده
دوباره export بشه (کوکی‌های اینستاگرام هر چند هفته منقضی می‌شن، این یه کار تکرارشونده‌ست).

### لینک APKPure کار نمی‌کنه
⚠️ این بخش وابسته به ساختار HTML صفحه‌ی APKPure هست و ممکنه با تغییر سایت خراب بشه.
اگه خطا داد، پیام دقیق خطا رو نگه دار تا الگوی استخراج لینک آپدیت بشه.

### لینک پلی‌لیست/ست ساندکلاود چطور کار می‌کنه؟
✅ به‌جای دانلود کل پلی‌لیست به‌صورت یه فایل، بات لیست تک‌تک ترک‌ها رو می‌گیره و
برای هر کدوم یه دانلود جدا (job مستقل) می‌سازه؛ پیام وضعیت اصلی به‌صورت زنده
«X از N دانلود شد» آپدیت می‌شه تا همه‌ی ترک‌ها برسن. تشخیص «پلی‌لیسته یا نه»
از روی خودِ URL نیست (لینک‌های کوتاه‌شده‌ی اپ موبایل مثل `on.soundcloud.com/xxx`
هیچ نشونه‌ای تو متن لینک ندارن)، بلکه واقعاً از yt-dlp پرسیده می‌شه - پس هر
شکل لینکی (کوتاه‌شده یا کامل با `/sets/`) درست کار می‌کنه.
