# 🎉 خلاصه کامل بات دانلودر

## 🆕 آپدیت سنگین اخیر

### تنظیمات شخصی کاربر (`/settings`)
Thumbnail دلخواه (`/set_thumb` یا فقط فرستادن عکس)، افکت اسپویلر، ارسال اجباری
به‌صورت فایل/سند، تغییر نام فایل (فقط برای لینک‌های فایل مستقیم/غیرپلتفرمی مثل
گوفایل/دراپ‌باکس/مدیافایر و غیره)، اسکرین‌شات پیش‌نمایش، timezone.

### پنل ادمین پیشرفته‌تر
`/topsites` (پرکاربردترین سایت‌ها + دامنه‌های unknown برای فهمیدن چی باید به
`LinkDetector` اضافه بشه)، `/userinfo` (breakdown سایت‌های یه کاربر خاص)،
`/broadcast` (پیام همگانی به همه یا فقط فعال‌های ۷ روز اخیر).

### تجربه‌ی کاربری دانلود
نمایش جایگاه صف وقتی چند دانلود هم‌زمان در جریانه، هشدار حجم قبل از دانلود
برای فایل‌های مستقیم بزرگ (با تاییدیه)، پلی‌لیست/ست ساندکلاود (هر ترک = یه
دانلود جدا، دقیقاً مثل پلی‌لیست/آلبوم اسپاتیفای).

### امنیت
چک مالکیت رو همه‌ی دکمه‌های حساس (لغو/retry/تغییر کیفیت/رنیم) - جلوگیری از
دستکاری دانلود یه کاربر دیگه با حدس‌زدن job_id؛ فیلتر SSRF رو لینک‌های
ورودی (رد کردن IPهای داخلی/لوکال سرور).

### پایداری و نگهداری
پاک‌سازی خودکار جاب‌های «زامبی» (گیرکرده بیش از حد به‌خاطر کرش worker)،
`docker-compose.yml` کامل‌تر (redis+postgres+bot+worker+beat)، چندتا الگوی
جدید تو مترجم خطای yt-dlp (DRM، دیسک پر، ffmpeg نصب‌نشده، تغییر ساختار سایت).

## 📜 تاریخچه‌ی تغییرات (آخرین بروزرسانی)

### 🐛 باگ‌های رفع‌شده
1. **پیام «در حال دانلود» پاک نمی‌شد** - بعد از ارسال فایل (موفق یا ناموفق)، پیام وضعیت حالا خودکار پاک می‌شه.
2. **دکمه‌ی «تلاش دوباره» پیام رو برای همیشه ول می‌کرد** - چون `status_message_id` بعد از retry آپدیت نمی‌شد. الان درست شده.
3. **`DownloadStats` روی اولین رکورد هر روز کرش می‌کرد** - `None += 1` روی فیلدهای تازه‌ساخته‌شده. الان مقدار اولیه‌ی صفر صریحاً ست می‌شه.
4. **لینک از وسط متن آزاد درست استخراج نمی‌شد** - اگه کاربر قبل/بعد لینک یه توضیح می‌نوشت (مثلاً «ایول + لینک»)، کل متن به‌عنوان URL به yt-dlp می‌رفت. الان فقط خودِ لینک با regex جدا می‌شه.
5. **فرمت‌های Instagram/کیفیت خاص گاهی «Requested format is not available» می‌داد** - الان اگه فرمت درخواستی نبود، خودکار با `best` دوباره امتحان می‌کنه.
6. **استخراج metadata (yt-dlp) کل بات رو برای همه‌ی کاربرا قفل می‌کرد** - چون `subprocess.run` مستقیم و بلاکینگ تو event loop اصلی اجرا می‌شد. الان تو ترد جدا (`asyncio.to_thread`) اجرا می‌شه + سقف ۵ تا همزمان.
7. **بات به هر عکس/فایل تو گروه با پیام «لینک بفرست» جواب می‌داد** - حالا این فقط تو چت خصوصی جواب داده می‌شه، تو گروه ساکت می‌مونه.
8. **سقف حجم فایل (`MAX_FILE_SIZE_MB`) الان روی ۲۰۰۰ مگابایته** - چون پروژه از Local Bot API Server استفاده می‌کنه، دیگه محدودیت ۵۰ مگی تلگرام معمولی وجود نداره و فایل‌های حجیم هم بدون مشکل آپلود می‌شن.

### ✨ فیچرهای جدید
1. **حذف خودکار پیام وضعیت** بعد از پایان کار (موفق/ناموفق).
2. **ریپلای به پیام اصلی کاربر** هنگام ارسال فایل (با fallback اگه پیام اصلی پاک شده بود).
3. **ری‌اکشن روی پیام کاربر** - 👍 موقع موفقیت، 👎 موقع شکست.
4. **معرفی خودکار در گروه** - وقتی بات به یه گروه اضافه می‌شه، خودش رو معرفی می‌کنه و می‌گه بهش دسترسی ادمین/حذف پیام بدن (متن قابل‌ویرایش با `/texts`).
5. **شبکه‌ی ایمنی گلوبال (`dp.error()`)** - هر خطای پیش‌بینی‌نشده فقط لاگ می‌شه، کل بات نمی‌خوابه.
6. **پشتیبانی Pinterest** - عکس یا ویدیوی پین، خودکار بعد از دانلود تشخیص داده می‌شه.
7. **پشتیبانی APKPure** - دانلود فایل APK با اسکرپ کردن صفحه‌ی اپ (⚠️ تست زنده نشده، نیاز به تست واقعی رو سرور).

### ⚠️ شناخته‌شده، ولی هنوز حل نشده
- **APKMirror پشتیبانی نمی‌شه** (لایه‌ی ضد-بات پیچیده‌تره).
- **جستجوی تورنت (مگنت‌لینک/Bitsearch/Nyaa)** ساخته نشد - این قابلیت عمدتاً برای پیدا کردن محتوای دارای کپی‌رایته و عمداً پیاده‌سازی نشد.
- **دانلود APK مستقیم از گوگل‌پلی** (نه از آینه‌ها) ساخته نشد - نیاز به دور زدن سیستم پرداخت/احراز هویت گوگله.
- **کوکی اینستاگرام** هر چند هفته منقضی می‌شه و نیاز به export دستی دوباره داره (نمی‌شه خودکارش کرد بدون لاگین برنامه‌نویسی‌شده که ریسک بلاک شدن اکانت داره).
- دکمه‌های اینلاین تلگرام **اصلاً رنگ ندارن** (پارامتر `style` تو کد فقط ظاهریه و توسط تلگرام نادیده گرفته می‌شه؛ این یه محدودیت خودِ تلگرامه، نه چیزی که بشه دور زد).

## 🏗️ ساختار

### بخش‌های اصلی:

#### 1. **بات تلگرام** (`bot/`)
- دریافت پیام و لینک در گروپ

- User - کاربران

#### 3. **Worker/Queue** (`worker/`)

- LinkDetector - شناسایی سایت
- MetadataExtractor - اطلاعات موسیقی

## 🚀 نحوه استفاده

### 1. نصب (۲ دقیقه)
```bash
git clone <repo>
cd downloader_bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# BOT_TOKEN را تکمیل کنید
```

### 2. اجرای ساده (بدون Celery)
```bash
python -m bot.main
```

### 3. اجرای کامل (با Celery)
```bash
# 3 ترمینال:
python -m bot.main
celery -A worker.celery_app worker -Q download,upload
celery -A worker.celery_app beat
```
