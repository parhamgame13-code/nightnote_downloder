## [Unreleased] — 2026-10-25 (بسته‌ی آماده‌سازی برای استقرار)

بسته‌ی کاملِ «رفع باگ + بهینه‌سازی + آماده‌سازی سرور». همه‌ی ۱۰۱ تست پاس، `ruff check` صفر خطا.

### ✨ قابلیت‌های جدید
- **🚫 بن کاربر واقعی شد**: `/ban <id> [دلیل]` و `/unban` برای ادمین‌ها (یا ریپلای روی پیام فورواردشده) — فیلد و CRUD از قبل بود ولی هیچ چکی بهش وصل نبود؛ الان کاربر بن‌شده تو مسیر لینک و آپلود بلاک می‌شه (ادمین‌ها مصون).
- **📋 `/history`**: تاریخچه‌ی ۱۰ دانلود آخر کاربر با وضعیت/حجم/تاریخ به وقت timezone خودش.
- **🔒 `ALLOWED_GROUP_IDS` حالا enforce می‌شه**: خالی = همه‌ی گروه‌ها (رفتار قدیمی)؛ پر = فقط همون‌ها. قبلاً تنظیم مرده بود.
- **🎧 مقاوم‌سازی اسپاتیفای** (بدون دست زدن به DRM): زنجیره‌ی منبع شد یوتیوب → **ساندکلاود (scsearch)** → **پیش‌نمایش رسمی ۳۰ ثانیه‌ای اسپاتیفای** (با برچسب صادقانه‌ی «پیش‌نمایش» در عنوان).

### 🔐 امنیت
- **فیلتر SSRF جدید و مشترک** (`utils/url_safety.py`): فرم‌های عددی IP (اعشاری/هگز/اکتال مثل `2130706433` یا `0x7f000001`)، آدرس‌های `::ffff:127.0.0.1` و **resolve واقعی DNS** — هم بات هم ورکر استفاده می‌کنن.
- **ریدایرکت‌های امن**: دانلود مستقیم فایل (ورکر) و probe حجم (بات) حالا ریدایرکت‌ها رو دستی و با چک SSRF در هر hop دنبال می‌کنن — لینک عمومی که 302 به `169.254.169.254` می‌ده دیگه fetch نمی‌شه.
- **Path traversal بسته شد**: اسم فایل از `Content-Disposition`/URL قبل از نوشتن روی دیسک پاک‌سازی می‌شه (`utils/filename.py`).
- **چک مالکیت** روی دکمه‌های لینک مستقیم (`dl_renew` / `dl_delete` / `dl_stats` / `dl_qr`) — قبلاً هر کسی می‌تونست فایل/لینک کاربر دیگه رو حذف یا تمدید کنه.
- پیام خطای کاربر فقط type استثنا رو نشون می‌ده (بدون نشت مسیرها/توکن‌ها).
- پورت کانتینر Local Bot API فقط روی `127.0.0.1` هاست.

### 🐛 رفع باگ‌ها
- **فیچر «عکس بفرست → لینک مستقیم بگیر» دوباره کار می‌کنه** — هندلر `F.photo` عکس‌ها رو نمی‌بلعه (`SkipHandler`).
- **`/cancel` حالا واقعاً همه‌ی ۱۰ حالت انتظاری رو لغو می‌کنه** (قبلاً ویرایش متن ادمین با پیام بعدی overwrite می‌شد).
- **شکست کاذب دو job همزمان با همون فایل** حذف شد (constraint یونیک `telegram_file_id` برداشته شد + migration 008 + فال‌بک IntegrityError در بات و ورکر و کش).
- **مسابقه‌های دابل‌کلیک بسته شد** — ادعای اتمیک جاب (`claim_for_processing`) در ۵ نقطه‌ی dispatch؛ دیگر دو بار دانلود ساخته نمی‌شه و status ورکر برگردونده نمی‌شه.
- کلید کش برای لینک‌های query-دار اصلاح شد (فایل غلط از کش سرو نمی‌شد) + باگ قدیمی `HTTPS://` با حروف بزرگ.
- autoretry سراسری Celery حذف شد (خطای گذرای DB دیگه دانلود تکراری نمی‌سازه).
- «پرکاربردترین سایت» در `/stats` الان mode واقعیه، نه آخرین سایت.
- چک سقف روزانه قبل از پردازش سنگین انجام می‌شه.

### ⚙️ عملیات (Ops)
- **نگهبان فضای دیسک** (`check_disk_space` هر ۱۵ دقیقه): هشدار ۸۵٪ / بستن موقت دانلودها ۹۵٪ / برگشت با هیسترزیس ۸۰٪.
- **پاک‌سازی تاریخچه** (`cleanup_old_jobs` روزانه، `JOB_RETENTION_DAYS=90`).
- **گزارش خطای روزانه** (`daily_error_digest` ساعت ۹ UTC): ۵ الگوی پربسامد ERROR دیروز برای ادمین‌ها؛ روزِ سالم ساکت.
- `run.py` وب‌سرور لینک مستقیم رو هم (وقتی `DIRECT_LINK_ENABLED`) خودش بالا میاره.
- systemd units: کاربر غیر-root `downloader` + hardening (`ProtectSystem=strict` و ...)؛ اسکریپت `setup_downloader_bot.sh` با مدل جدید (/opt، کاربر اختصاصی، alembic، .env) بازنویسی شد.
- وابستگی‌های مرده حذف شد (صف `detect`، `REDIS_DB_CACHE`، `MUSIC_*`)؛ `db/seed.py` به کلید فعال trim شد؛ `utils/persian.py` حذف.

### 🌐 Local Bot API Server
- سرویس `telegram-bot-api` پیش‌فرض جزو `docker-compose.yml` (کلیدهای عمومی Telegram Desktop به‌عنوان پیش‌فرض؛ قابل بازنویسی با `.env`)؛ `run.sh` خودش بالا میارش یا از کانتینر مشترک موجود استفاده می‌کنه؛ ولوم فایل‌هاش به worker هم mount می‌شه (پاک‌سازی دوبلِ دیسک).
